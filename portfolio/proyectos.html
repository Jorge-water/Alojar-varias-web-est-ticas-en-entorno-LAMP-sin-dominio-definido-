Proyectos

Algunos trabajos realizados durante mi formación en ASIR.

Servidor web Apache

Instalación y configuración de Apache en Debian para alojar varias páginas web estáticas. Configuración del servicio, estructura de directorios, permisos y comprobación de acceso desde el navegador.

Virtualización con VirtualBox

Creación de máquinas virtuales Linux, configuración de red NAT, redirección de puertos y acceso remoto mediante SSH.

Administración de redes

Prácticas de direccionamiento IPv4, configuración de interfaces, routing y resolución de incidencias de conectividad.

Git y GitHub

Uso de Git para control de versiones y publicación de proyectos web mediante repositorios y GitHub Pages.
